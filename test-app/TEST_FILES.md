# Test Files Reference

## Overview

The test app includes 13 test files covering all MIME detection scenarios.

## Test Files

### 1. **JPEG Image (remote)**
- **Source:** https://picsum.photos (Unsplash)
- **Tests:** Remote JPEG detection via Content-Type header
- **Expected:** `image/jpeg` from content-type-header

### 2. **PNG Image (remote)**
- **Source:** https://picsum.photos
- **Tests:** Remote PNG detection via Content-Type header
- **Expected:** `image/png` from content-type-header

### 3. **SVG Image (inline)**
- **Source:** Generated SVG with gradient
- **Tests:** SVG detection via MIME type (no magic bytes for XML-based formats)
- **Expected:** `image/svg+xml` from blob-type

### 4. **MP4 Video (local)**
- **Source:** `/test-files/video.mp4` (Big Buck Bunny, 968KB)
- **Magic bytes:** `00 00 00 20 66 74 79 70` (ftyp at offset 4)
- **Tests:** Magic byte detection for MP4, Range request support
- **Expected:** `video/mp4` from magic-bytes (high confidence)

### 5. **WebM Video (local)**
- **Source:** `/test-files/video.webm` (1MB)
- **Magic bytes:** `1A 45 DF A3` (EBML header)
- **Tests:** WebM EBML header detection
- **Expected:** `video/webm` from magic-bytes (high confidence)

### 6. **MP3 Audio (local)**
- **Source:** `/test-files/audio.mp3` (8.5MB, SoundHelix)
- **Magic bytes:** `49 44 33` (ID3)
- **Tests:** MP3 ID3 tag detection, large file handling
- **Expected:** `audio/mpeg` from magic-bytes (high confidence)

### 7. **JSON File (local)**
- **Source:** `/test-files/test.json`
- **Tests:** JSON detection via Content-Type header (no magic bytes for text formats)
- **Expected:** `application/json` from content-type-header

### 8. **Markdown File (local)**
- **Source:** `/test-files/README.md`
- **Tests:** Markdown detection via Content-Type or extension fallback
- **Expected:** `text/markdown` from content-type-header or file-extension

### 9. **Fake ZIP (local)**
- **Source:** `/test-files/fake-zip.txt`
- **Content:** Text file starting with "PKZIP.EXE is a tool..."
- **Tests:** Ensures "PKZIP" text prefix is NOT detected as ZIP
- **Expected:** `text/plain` from content-type-header (NOT `application/zip`)

### 10. **ZIP Archive (inline)**
- **Source:** Generated bytes `50 4B 03 04`
- **Magic bytes:** `PK\x03\x04` (valid ZIP local file header)
- **Tests:** Valid ZIP signature detection
- **Expected:** `application/zip` from magic-bytes (high confidence)

### 11. **Plain Text (inline)**
- **Source:** Generated text with `type: 'text/plain'`
- **Tests:** Plain text detection via Blob.type property
- **Expected:** `text/plain` from blob-type

### 12. **Data URL (PNG)**
- **Source:** `data:image/png;base64,...`
- **Tests:** Data URL parsing and magic byte detection
- **Expected:** `image/png` from magic-bytes (high confidence)

### 13. **JPEG Named .txt (inline)**
- **Source:** Valid JPEG bytes in file named `image.txt`
- **Magic bytes:** `FF D8 FF` (JPEG SOI marker)
- **Tests:** **Critical test** - Magic bytes MUST override file extension
- **Expected:** `image/jpeg` from magic-bytes (with overridden: `text/plain` from file-extension)

## Key Test Scenarios

### Magic Byte Priority
- Test #13 (JPEG named .txt) - Proves magic bytes override extension
- Test #10 (ZIP) vs Test #9 (Fake ZIP) - Proves exact signature matching

### Text Format Detection
- Tests #7, #8, #11 - No magic bytes, rely on MIME type or extension
- Test #9 - Proves no content heuristics for text formats

### Remote vs Local
- Tests #1, #2 - Remote files (CORS-safe)
- Tests #4, #5, #6, #7, #8, #9 - Local files (no CORS issues)
- Tests #3, #10, #11, #13 - Inline generated (instant)
- Test #12 - Data URL (embedded)

### Performance
- Test #6 (8.5MB MP3) - Only reads 64 bytes via Range request
- All local files support Range requests (206 Partial Content)
- Parallel HEAD + Range requests for HTTP/HTTPS URLs

### Fallback Chain
- High confidence: Magic bytes detected (#4, #5, #6, #10, #12, #13)
- Medium confidence: Content-Type header (#1, #2, #7) or Blob.type (#3, #11)
- Low confidence: File extension fallback (#8 if Content-Type missing)

## Detection Performance

| File | Size | Detection Method | Time Expected |
|------|------|------------------|---------------|
| Local files | Any | Range: 64 bytes | ~10-50ms |
| Remote images | Any | HEAD request | ~100-300ms |
| Data URLs | Any | Decode base64 | ~5-10ms |
| Inline generated | <1KB | Immediate | ~1ms |

## Expected Behavior

### Fast Switching
- Keyboard navigation should be instant
- AbortController cancels previous requests
- Object URLs properly cleaned up
- No memory leaks

### Error Handling
- Range request fails → falls back to Content-Type header
- HEAD request fails → falls back to extension
- All requests time out → returns unknown

### Display
- Detection info shows MIME type, source, and confidence
- Overridden detection is displayed when magic bytes override other methods
- Loading state appears during detection
- Error state for failed detections
